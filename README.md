# Weather App
This is a very simple weather app build using Flask as backend, livereload to serve a local server and apply live changes, requests to make simple HTTP requests.
## Requirements
The applications uses the following dependencies Flask, Livereload and Requests. You can either install them manually or run the following command to install all dependencies:
```
pip install -r requirements.txt
```
## Usage
You simply run the following command to start the development server:
```
python app.py
```
This will start a local development server at ``127.0.0.1:5000``. Visiting the url you will be meet by a search bar, where you can enter any city and request the weather data. This will display the current hourly weather and a forecast where you can see 7 days of weather forecast with a chart.
